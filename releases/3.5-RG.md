# Rich Text Area 3.5-RG

This release merges all previously committed feature branches into `main`,
including `MassiveFeatureUpdate` and `AddFeatures`.

- Page layout and document view, headers/footers, page formats and field APIs.
- Numbered-list start values and improved paragraph padding.
- Horizontal scrolling and caret visibility improvements.
- Table cell replacement/selection corrections and Unicode/emoji preservation.
- Correct line height and clickable glyphs for final empty paragraphs.
- JavaFX 25.0.4 alignment and updated caret-shape calls.

This is the RainerGa fork of Gluon's RichTextArea. The fork version is provided
through this GitHub release, not Maven Central. Requires JDK 25 and JavaFX
25.0.4; library bytecode targets Java 21. The matching offline Noto emoji
dependency, original notices and corresponding sources are included in the
bundle. See RELEASING.md for installation and reproducible build instructions.

Field and style APIs include experimental functionality: page-number/count
fields still contain placeholder evaluation and style inheritance resolution
is not implemented. Legacy API-mismatched tests are not enabled; the release
pipeline runs compatible model regressions and the pinned editor GUI suite.
The release also includes the now committed performance work: revision-based
buffer invalidation, indexed text-piece access and virtualized layout updates.
